# ИИ-советник MAX v0.2

Экспериментальный Android-клиент для анализа уведомлений MAX через облачный ИИ.

## Установка
1. Откройте GitHub Actions > Build Android APK, скачайте артефакт MaxAIAdvisor-debug-apk.
2. Распакуйте ZIP и откройте app-debug.apk на Android.
3. В приложении введите HTTPS URL собственного сервера /analyze и его токен. Ключи OpenAI/Gemini/DeepSeek хранятся исключительно на сервере.
4. Разрешите уведомления и доступ к уведомлениям для советника. Включите переключатель мониторинга.

## Ограничения
- Бот не читает переписку напрямую: только отображаемое MAX содержимое уведомлений.
- Без собственного сервера и ключей провайдера ИИ-анализ недоступен.
- Токен и история хранятся в обычных SharedPreferences, для конфиденциальных чатов текущий прототип **не подходит**.
- Не используйте в отношении чужих или рабочих персональных данных без соответствующего основания и разрешения.
- GitHub Actions собирает тестовый debug APK, не релизную сборку.
