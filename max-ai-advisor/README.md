# ИИ-советник Lite v0.3

Ручной анализ текста из MAX или других приложений: вставьте текст или выберите Android «Поделиться» > «ИИ-советник Lite».

Приложение НЕ имеет разрешений на чтение уведомлений, не использует NotificationListenerService и не работает в фоне для анализа переписки.

## Настройка
1. Установите APK.
2. Введите HTTPS-адрес своего сервера с /analyze и токен.
3. Выберите OpenAI, Gemini или DeepSeek. Ключи провайдеров хранятся на сервере.
4. Нажмите «Анализировать переданный текст» и подтвердите отправку. Результаты доступны через «Обновить историю».

Без настроенного сервера и API-ключей облачный анализ не работает. В этой тестовой версии токен и история сохраняются без шифрования в SharedPreferences. Не используйте для конфиденциальных данных.

GitHub Actions собирает тестовый debug APK. Прохождение Google Play Protect не гарантируется.
